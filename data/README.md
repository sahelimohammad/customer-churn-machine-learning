# Dataset / مجموعه‌داده

**Iranian Churn**, UCI Machine Learning Repository (2020), DOI: https://doi.org/10.24432/C5JW3Z

- 3,150 rows, 13 predictors, one binary `Churn` target.
- `Churn = 1` denotes churn; `Churn = 0` denotes no churn.
- UCI describes the features as aggregated over the first 9 months and churn as observed at month 12.
- This file is the same `CustomerChurn.csv` provided in all three original ZIP archives.
- Source dataset license: **CC BY 4.0**. Attribution is required when sharing or adapting it: https://creativecommons.org/licenses/by/4.0/
- The dataset may contain exact duplicate records. The enhanced ML scripts remove exact duplicates **before splitting**, to reduce duplicate leakage between train and test.
